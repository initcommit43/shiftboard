# shiftboard_api (EXPERIMENTAL)
Single source of truth for the shiftboard API. The Dart client of the worker
app and the TypeScript client of the agency dashboard are generated from
this file.

Conventions:
- REST under `/api/v1`
- errors as RFC 9457 problem details (`application/problem+json`) with a
  machine-readable `code` that clients translate
- page/size pagination for lists, pages start at 0
- UUID v7 identifiers
- changes stay backward compatible

Authentication: `POST /auth/login` returns a short-lived access token and a
refresh token. The access token is sent as `Authorization: Bearer <token>`.
Refresh tokens are single use: `POST /auth/refresh` returns a new pair.
